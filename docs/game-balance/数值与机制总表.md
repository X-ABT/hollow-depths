### 1.2 属性重算顺序（Build）

出处：`src/core/Build.ts` `recompute()` 与 `emptyStats()`。

```
空表(角色 base 初始化) → char.perk（角色固有被动）
  → 逐件被动 apply() → build.petBonus（上阵宠物增益+收藏里程碑）→ 得最终 Stats
```

- 槽位上限于运行时定义：`MAX_WEAPON_SLOTS=6`、`MAX_PASSIVE_SLOTS=6`（Build.ts:11-12）。
- `weaponLevels/passiveLevels`（商店永久起始等级）在新建 `Build` 时注入，新增武器/被动以 `startLevel(id, maxLevel)` 起手（Build.ts:90-95）。
- 每次 `recompute()` 使 `build.version++`；常驻型武器（圣环）依据版本号同步数值而不重建（WeaponSystem.ts:55-56,83-85）。

### 1.3 玩家运行时属性同步与移动

出处：`src/core/Game.ts:931-1001`、`src/ecs/World.ts`。

- 每逻辑步把 `build.stats` 写入 `world.player`（speed/armor/regen/damageMul/critChance/critMult/xpMul/pickupRange，Game.ts:947-954）。
- 移动：`p.x += mx * p.speed * dt`（Game.ts:958-959）。
- 回复：`regen > 0 且 hp < maxHp` 时 `hp += regen*dt`（Game.ts:986）。
- 出生短暂无敌 `iframe = 1.6s`（Game.ts:518）；玩家受击默认无敌帧 0.6s（Damage.ts:144，见第六节）。
- 竞技场半径 `world.arenaR`（终焉边界）若 >0，玩家被钳制在圆心 `arenaX/arenaY` 半径内（Game.ts:963-972）。

### 1.4 升级经验曲线

出处：`src/core/MathUtil.ts:38-47`。

分段公式（达到 10 级后指数递增项 ×1.15，升级放缓约 15%；只动指数项 → 每级所需严格递增、不倒退）：

```
xpForLevel(level) = floor(5 + level*6 + level^1.55 * 2.2)            // level < 10
xpForLevel(level) = floor(5 + level*6 + level^1.55 * 2.2 * 1.15)     // level >= 10
```

- 常量：`XP_SOFTEN_LEVEL=10`（起效等级，10→11 档即生效）、`XP_SOFTEN_MUL=1.15`（指数项乘数）。
- 1 级出生 `xpNext=10`（World.ts:97、Game.ts:516）；升到 level 后新阈值 = `xpForLevel(level)`（PickupSystem.ts:89）。
- 抽样：Lv1→2 需 10（出生硬编码，不走公式）；2→3=23、3→4=35、4→5=47、5→6=61、9→10=125（Lv<10 各档不变）；**10→11=154**（原 143）、11→12=175（原 161）、12→13=196（原 180）、13→14=217（原 200）。

## 二、武器与进化

### 2.0 武器通用规则

出处：`src/data/weapons.ts`、`src/ecs/systems/WeaponSystem.ts`、`src/ecs/Damage.ts`。

- 基础武器 **8 把**（原 7 把 + 新增「飞剑」），均 `maxLevel=12`（`LV12`，weapons.ts:313）；等级取值 `lv(level)=min(level,12)-1`。
- 装备上限 6 槽；每级冷却在开火后置为 `cd[li] / stats.fireRateMul`，下限 0.02s（WeaponSystem.ts:89-93）。
- 基础伤害在系统层已乘全局乘区：`dmg = def.dmg[li] * stats.damageMul`（WeaponSystem.ts:69）。
- 每把武器开火时 `srcId = slot*16`（WeaponSystem.ts:67）；同一轮的多个子投射物用 `srcId + k` 拆来源，配合 Damage.ts 的「同类来源免疫间隔」保证一次开火可多次命中不同目标（见第六节）。
- 常驻武器（圣环）不走冷却：以签名 `level*1e6 + count*1e3 + round(b[li])` 判断是否重建，属性变化时只 `syncPersistent`（同步 dmg/critChance/critMult）不重建（WeaponSystem.ts:75-88）。

### 4.0 敌人总览与通用规则

出处：`src/data/enemies.ts`、`src/ecs/Components.ts`、`src/ecs/Spawn.ts`、`src/ecs/systems/EnemyAISystem.ts`、`src/ecs/Damage.ts`。

- AI 枚举（Components.ts:10-26）：`Chase/Dash/Grow/Blink/Spiral/Splitter/Shielded/Trickster/BossHerald/BossCalamity/BossEndless/Gunner/BossLament/BossMaw/BossNest`（0~14）。
- 生成实体时（Spawn.ts:60-129）：`radius=def.radius*scale`；`maxHp=def.hp*hpMul*scale*world.enemyHpMul×(bossOrGunner?1:world.minionHpMul)`；`damage=def.damage*dmgMul×(bossOrGunner?1:world.minionDmgMul)`。`bossOrGunner = def.boss || def.id==='gunner'`——**关卡3 小怪倍率只乘给非 Boss 且非深渊炮手**（普通/精英/召唤全覆盖）；史莱姆伤害强制固定 3、不吃任何伤害倍率。`speed/armor/xp` 取自定义；`castMul` 默认 1，无尽 Boss 随轮次放大。
- **关卡2（第二个地牢）**：与关卡1 完全相同的波次/Boss/胜负流程与机制，仅 `world.enemyHpMul=2`（所有敌怪——含 Boss 召唤物与分裂魔分身——血量 ×2）；伤害/经验/掉落/AI/阶段阈值均不变。
- **特殊关卡（挑战）**：`world.enemyHpMul=3`（全怪 HP×3）；小怪/精英/波次成长/深渊炮手（古神批后）完全照关卡1。**Boss 改为三连批**：首波 180s、之后每批间隔 180s，按 `BOSS_ORDER`（古神→灾厄→终焉）**同种×3** 同时刷出（圆周 120° 均布）；**3 只全灭才出下一批**；**击败一轮 3 只终焉即通关**。批间按「全灭耗时」结算快杀激励（与关卡1/2 同规则）。同批 Boss **逐只击杀**——击杀 Boss 的清屏不再连坐同批 Boss（见第七节清屏规则）。
- **关卡3（第三个地牢）**：波次/生成/成长与关卡1 相同，流程照关卡1 节奏但 Boss 换成 **泣灵(5:00)→渊喉→巢母**（`STAGE3_ORDER`，击杀巢母即胜利）。**Boss 不吃全局倍率**（`enemyHpMul=1`、仍随 `hpScale(t)` 成长）；**非 Boss（除深渊炮手）** 额外 `minionHpMul=3`（HP ×3）、`minionDmgMul=2`（伤害 ×2）。**深渊炮手 3:00 起固定周期刷新（与 Boss 是否在场无关）**，数值见 4.2。开局至首只泣灵被击败前普通怪基础生成倍率 0.5；**击败泣灵后升满 1.0**（关卡3 无古神，走 `onStage3BossDown()`，见 5.2）。
- 无尽幽墟与宠物远征不套用小怪/血量倍率（均 =1）。入口在标题弹层：**无尽幽墟（置顶）→ 特殊关卡 → 关卡1 → 关卡2 → 关卡3**；`再来一局` 保持当前关卡难度。
- Boss 血条 / 死亡回调由 CleanupSystem 统一处理（见第七节）；终焉在 `Damage` 层有专属无敌拦截。
- 敌人受击闪白 `flash=0.12`；受击即 `aggro=1`（史莱姆据此转追击，Spawn.ts / Damage.ts:59-61）。

#### 4.3.1 古神 BossHerald（EnemyAISystem.ts:217-316）

按血量分三阶段：`>66% 阶段0`、`>33% 阶段1`、`≤33% 阶段2`；切阶段时 `timer=1.2s`。

- 阶段 0（召唤）：全速追击；周期进入 0.7s 蓄力后**召唤 3 只亡魂**（位置偏移 70px，`hpMul=3.2`，`xp=0.3` 几乎不给经验）。

#### 4.3.2 灾厄 BossCalamity（EnemyAISystem.ts:318-359）

### 5.2 生成率与密度公式（waves.ts:42-90）

- `spawnRate(t)=min(34, 0.6 + t*0.052)`（只/秒）
- 密度 `DENSITY_STEPS`：0s→×1、120s→×1.5、360s→×2、540s→×2.5、660s→×3
- 敌人成长：`hpScale(t)=1+(t/60)*0.35`（每分钟 +35%）；`damageScale(t)=1+(t/60)*0.18`（每分钟 +18%）
- 实际单帧生成：`rate = spawnRate * densityMul * earlySpawnMul * minionRushMul × (巢母在场 ? world.minionBurstMul : 1)`；标准局 Boss 在场且**非巢母战**再 ×0.12——巢母（关卡3 最终 Boss）是「指挥小怪的母体」，在场时解除该压制并让狂潮生效（SpawnSystem.ts:410-418）。
- `earlySpawnMul`（普通怪基础生成倍率）：开局 `0.5` → 击败古神后 `0.7`（关卡1/2/特殊）→ **关卡3 击败泣灵后 `1.0` 满额**（SpawnSystem.ts `onHeraldDown` / `onStage3BossDown`）。

### 5.3 Boss 出场（waves.ts:50-62 + SpawnSystem.ts）

- 标准 `BOSS_ORDER=['herald','calamity','endless']`；`FIRST_BOSS_AT=300`；`NEXT_BOSS_GAP=240`。
- 关卡3 `STAGE3_ORDER=['lament','maw','nest']`（waves.ts:57-59）：照关卡1 节奏——首只泣灵 5:00 出场，击杀后 4:00 渊喉，再 4:00 巢母；**击杀巢母即胜利**（不触发 `onHeraldDown`，炮手改固定时间点刷新）。`FIRST_BOSS_AT`/`NEXT_BOSS_GAP` 与标准一致，快杀激励同样生效。
- 无尽 `ENDLESS_ORDER=['herald','calamity','lament','maw','endless']`；`ENDLESS_FIRST_BOSS_AT=240`；首只按 240s 后间隔逐轮递减（见 5.5）。
- **快杀激励** `bossHpMulByKillTime`（waves.ts:97-104）：击杀耗时 ≤15s→×10、≤30s→×5、≤60s→×4、≤90s→×3、≤120s→×2、>120s→×1；该倍率还会**永久乘进普通怪刷新速率**（`minionRushMul *= mul`，SpawnSystem.ts:104），不设回退。
- **适用范围（防漏清单）**：快杀激励对 **关卡1 / 关卡2 / 特殊关卡** 全部生效；**无尽幽墟不套用**（Boss 击杀回调早退）。特殊关卡按「本批 3 只全灭耗时」结算并推进下一批。**新增任何非无尽关卡都必须沿用同一套激励调度**（单 Boss 流程走 `scheduleNextBoss`；三连批走 `onSpecialBossKilled`）。
- **特殊关卡 Boss 三连批**：`specialSeq`（BOSS_ORDER 下标 0古神/1灾厄/2终焉）、首波/批间隔 `SPECIAL_FIRST_WAVE_AT=180` / `SPECIAL_WAVE_GAP=180`、每批 `SPECIAL_BATCH=3`（SpawnSystem.ts）。

### 5.4 随机四边刷新（SpawnSystem.ts）

- 普通怪按 **上/下/左/右 四边随机**选边：`SPAWN_SIDE_SECONDS=1s` 换一次边（每次随机重选 0..3，不再顺序轮转）。

- 单步生成上限 guard=64（防止极端掉帧后一次性铺满）。

### 6.1 投射物默认字段（Spawn.ts:8-44 为准；World.ts makeProj 与此一致）

### 6.2 命中与免疫间隔（Damage.ts:24-84, 154-170）

- 每敌人记录最近 `srcId` 与 `srcImmune` 免疫剩余；同源在免疫内不再命中 → 实现环绕/领域按节拍跳伤，也防子弹连帧重复命中。
- `immuneFor(behavior)`：Orbit 0.35 / Aoe 1.0 / Beam 0.3 / Field 0.4 / Mark 1.0 / 其他(Linear/Homing 等) 0.2。
- 伤害公式：先判暴击（`rng<critChance` → ×critMult），再减护甲：`dmg = max(1, dmg - armor)`；受击即 `aggro=1`、`flash=0.12`。
- 甲壳兽护盾（Shielded）：`hp > maxHp*0.5` 时伤害额外 ×(1−0.8)（即只吃 20%）。
- 欺诈者：受击后 `rng < 0.5` 闪现到玩家背后 100px。
- 范围爆炸 `explode`：边缘距离衰减 `falloff = 1 - 0.4*min(1, d/(radius+e.radius))`（边缘 60%）；`immune=1.0`；对玩家 tick 的敌方地面区在 CollisionSystem.ts:33-43 每 0.5s 结算 `dotDps*0.5`、玩家无敌帧参数 `iframe=0.25`。

### 6.3 玩家受伤（Damage.ts:144-152）

- `damagePlayer(amount, iframe=0.6)`：有 iframe 则返回 0；实际伤害 `max(1, amount-armor)`；并回调 `onPlayerHurt`（Game.ts 据此震屏）。
- 接触伤害（CollisionSystem.ts:201-223）：敌人每 0.5s 最多一次接触（`e.hitCd=0.5`），同帧求和一次结算；接触会轻微弹开敌人（反向 120）。
- 敌方弹幕命中玩家：`hostile` 投射物直接判碰撞（半径圆），伤害为投射物 damage。

### 6.4 各类行为的推进细节（ProjectileSystem.ts / CollisionSystem.ts）

- Homing：每 0.18s 用 `queryNearest(800)` 重锁；有限角速度转向 `turn*dt`。
- Orbit：`x = p.x + cos(orbitAngle)*orbitRadius`（跟随玩家），命中不消耗穿透。
- Aoe：半径从 r0 线性扩到 r1（lerp t=1-life/maxLife）。
- Beam：线段-圆命中，`along` 在 [−e.radius, length+e.radius]、`perp ≤ width/2+e.radius`；命中 `hits<pierce` 计数。
- Field：对玩家 `pr.follow` 时每帧贴玩家；对敌人命中把 `e.slowT=0.35、e.slowF=pr.slowF`，伤害跳 `dotDps*0.4`（CollisionSystem.ts:158-160）。
- Mark：到期 `explode(r1, damage, ...)`；Telegraph：到期在玩家判定圈内 `damagePlayer(damage)`。
- 溅射（CollisionSystem.ts:103-105）：`pr.splash>0` 时命中处 explode，半径=splash、伤害=`damage*0.6`、`srcId+8`、无暴击/击退。

- **Boss 死亡清屏规则（2026-09-08 起全局生效）**：任意 Boss 死亡**只清普通怪**（普通怪 + 普通召唤物如亡魂/幻影 + 分裂魔分身），**保留精英（分裂魔本体/甲壳兽/欺诈者/炮手）与全部 Boss**——修复特殊关卡同批 Boss×3 的连坐问题（连坐会用 releaseAt 绕过 `onBossKilled`，导致 `specialKills` 计数停摆、整批永远推不完、下一批 Boss 倒计时消失）。分裂魔本体与分身同为 splinter 定义，分身按 `e.growT(=gen)≥1` 区分清除（CleanupSystem.ts）。对关卡1/2/3 无副作用：单 Boss 流程中 Boss 死亡时场上本无第二只 Boss。

- 粮袋：`FOOD_COST_SHARDS=2` 碎片/袋；整包特惠 `FOOD_BULK_COST=100` 碎片换 `FOOD_BULK_COUNT=60` 袋。
- 饲养园投喂升级消耗 `foodToNext`（PetScreen.ts:594-599）。

### 8.5 上阵增益与收藏里程碑（pets.ts:201-349）

- 每只宠物固定一种增益 `PET_BUFFS`（见 8.1 表）：方向 `damage/fireRate/xp/speed`（乘区）与 `regen/maxHp`（固定量）；语义：每级提供量 × 宠物等级。
- 上阵即生效（≤3 只，同一只不重复计）：`Build.petBonus = applyLoadoutPetBonus(save)`（Game.ts:492-494）；作用点在角色 perk + 被动之后（Build.recompute 末尾）。
- **收藏里程碑**：拥有 3/6/9/12 只解锁「经验 +1%」档位（可叠加，`PET_MILESTONE_XP_PER_TIER=0.01`）。
- 远征模式只认 `EXPEDITION_BUFF_KINDS = {damage, fireRate, regen, maxHp}`（经验/移速无意义）。

### 8.6 局内战斗（PetSystem.ts:13-43 常量；Spawn.ts:149-175）

| 常量 | 值 | 语义 |
| --- | --- | --- |
| `PET_CHASE` | 205 | 追击/回归速度(px/s) |
| `PET_FLEE` | 300 | 灰心逃回速度 |
| `PET_ATK_BASE` | 0.85 | 攻击基础冷却(s) |
| `PET_ATK_PER_SCALE` | 0.055 | 每体积比例额外冷却（封顶 +0.9s） |
| `PET_REACH_BASE` | 34 | 撕咬基础范围(体积=1) |
| `PET_REACH_MAX` | 460 | 撕咬范围上限 |
| `PET_RECOVER` | 3.2 | 灰心恢复时长(s)，结束满血回归 |
| `PET_HURT_CD` | 0.6 | 受击结算间隔(s) |
| `PET_FORM_R` | 52 | 无目标时绕玩家队形半径 |
| `PET_SRC_BASE` | 3000 | 宠物伤害来源 id（+槽位） |

- 索敌：扫描半径 `max(34, reach+120)`，评分 = `当前血量 × (1 - 距离/扫描半径)` → 偏爱「近且厚」的目标（Boss/精英优先）。
- 攻击冷却：`PET_ATK_BASE + min(0.9, scale*PET_ATK_PER_SCALE)`；命中免疫 0.45s。
- 三种风格：**bite** 只打最优目标；**sweep** 主目标满伤、横扫扇区半角 0.95 rad、范围 `reach+110`、副目标 0.6 倍；**smash** 以目标为中心爆炸，半径 `max(34, reach*0.9)`（距离衰减见 explode）。
- 受击只算宠物自身判定半径（`radius+30` 扫描），每次 `PET_HURT_CD` 只吃一次伤害；`hp≤0` → 灰心逃跑（无敌）→ 恢复满血回归。
- 紧凑显示：`petCompact`（存档开关）隐藏巨兽本体、攻击特效仍在。

## 九、宠物远征模式

### 9.0 玩法结构（Game.ts:814-929、ExpeditionHub/Hud/Overlay）

- 入口：主界面「远征」→ 选宠营地（列表按稀有度降序）→ 开始第 N 关。存档点 `expBossStage`：首次 1 关，击败 Boss 关（6 的倍数）后从下一关续。
- 战斗：英雄宠物驻守左侧（世界坐标 0,0），自动平 A 最近敌宠；敌宠从右侧 x=920 屏外按 0.95s 间隔涌入、匀速左移、抵达英雄停下接触；玩家点按/空格/数字1 释放招牌技能（受 CD 限制）。
- 胜利：清空队列与场上 → 发星币奖励；失败：英雄 hp≤0 → 回营地。普通关/Boss 关都可连续自动续关（清关横幅 1.6s 后自动开下一关）。

### 9.1 关卡难度公式（`data/expedition.ts`）

| 旋钮/公式 | 值 | 含义 |
| --- | --- | --- |
| `BASE_TOTAL_HP` | 60 | 第 1 关敌宠总血量 |
| `TOTAL_HP_GROWTH` | 1.35 | 每关总血量成长倍率 |
| `BOSS_TOTAL_MUL` | 2.2 | Boss 关总血量再乘一档 |
| `MAX_COUNT` | 18 | 单关敌宠数量上限 |
| `DMG_GROWTH` | 0.1 | 接触伤害随关成长（刻意慢于血量） |
| `BOSS_BASE_DMG` | 8 | Boss 首次遭遇接触伤害 |
| `BOSS_DMG_PER_ROUND` | 3 | Boss 每重复一轮伤害增量 |

- 关内敌宠组成：普通关 第 1~2 关小怪档 / 3~4 中怪档 / 5~6 大怪档循环（`SMALL/MID/BIG` 复用 enemy id），`count = min(4+stage, 18)`，按 stage 种子确定性挑选。
- 每 6 关为 Boss 关（`BOSS_CYCLE=['herald','calamity','endless']` 按轮循环、越后越强）。
- 血量归一：`hpMul = targetTotalHp / Σ基础hp`（消除小/中/大档基础血量差造成的断崖）。
- 伤害：普通关 `dmgMul = 1+0.1*(stage-1)`；Boss 关 `dmgMul = (8 + 3*(round-1)) / 基础伤害`。
- 奖励星币：普通关 `20+5*stage`、Boss 关 `80+8*stage`（取整）。

### 9.2 英雄属性与战斗参数（ExpeditionSystem.ts:21-44, 106-170）

| 常量 | 值 | 语义 |
| --- | --- | --- |
| `HERO_SRC / SKILL_SRC / BEAM_SRC` | 9001 / 9002 / 9003 | 爪击/范围技能/光束的来源 id |
| `SPAWN_X` | 920 | 敌宠出生 x |
| `EXP_HP_MUL` | 6 | 英雄血量倍率（站桩需高缓冲） |
| `EXP_ATK_INTERVAL` | 0.6 | 平 A 间隔(s)，攻速增益按 `/ (1+v)` 缩短 |
| `EXP_REACH` | 600 | 平 A 索敌半径 |
| `SPAWN_GAP` | 0.95 | 敌宠出生间隔 |
| `SKILL_LV_MUL` | 0.25 | 技能每级增益（伤害/治疗 ×(1+0.25×等级)） |

- 英雄 hp = `hpFor×6 + maxHp增益`、dmg = `dmgFor ×(1+damage增益)`；只认远征增益子集（见 8.5）。
- 敌宠不吃主局 AI，统一「匀速左移 + 抵达英雄停下 + 接触伤害每 0.6s 一次」。

### 9.3 招牌技能（pets.ts:370-461）

每只宠物一个专属技能（见 8.1 表「招牌技能」列）；参数只有几种模板，缺失自动回退默认 nova：

| 技能（归属） | kind | cd(s) | dmgMul | radius | 备注 |
| --- | --- | --- | --- | --- | --- |
| 魂能爆发/灯焰新星/雾爆/荆棘新星（soulbat/paperlamp/mistfrog/sproutling） | nova | 5 | 4 | 140 | 范围爆发 |
| 铁壳冲撞/裂骨飞扑/霜刃突袭（rustbug/bonehound/frostcat） | dash | 6 | 3 | 200 | 击退 260，冲击中心偏移 hero.x+140 |
| 深渊吐息/噬光射线（abysshound/glowmoth） | beam | 4 | 5 | 540 | 水平光束，纵向 ±80 |
| 晶盾回响（crystalcoot） | heal | 7 | 2 | — | 回 `maxHp×0.5` |
| 龙息焚天（drake） | beam | 4 | 5 | 560 | 传说光束 |
| 星噬湮灭（stareye） | nova | 5 | 5 | 170 | 传说新星 |
| 翠芽治愈（budling） | heal | 7 | 2 | — | 回 `maxHp×0.5` |

- 技能伤害公式：`heroDmg × dmgMul × (1 + 0.25 × 技能等级)`；nova 触发 `explode(… critChance 0.1, critMult 2)`。
- 治疗量：`maxHp × heal比例 × (1 + 0.25 × 技能等级)`。
- 技能等级升级（营地，星币）：`skillUpgradeCost(lv) = 20 × (lv+1)`（0→1 花 20，1→2 花 40…，pets.ts:458-461）。

### 9.4 星币经济（expedition.ts:104-115、Game.ts:910-917）

- 星币 `starCoins` 是远征专属货币（独立于 petShards）：清关奖励按 9.1；击败 Boss 关推进存档点 `expBossStage`。
- 兑换碎片：`STAR_PER_SHARD=100` 星币 = 1 碎片（可自选数量，不整光）。

## 十、Boss 美术标准（程序化贴图）

出处：`src/render/Textures.ts`（逐只绘制）、`src/render/Renderer.ts`（呼吸表现）。

### 10.1 设计目标与硬性约束

- 风格＝**深渊幽邃风**：保持各 Boss 主题（多眼 / 角 / 时钟 / 漩涡 / 黑洞 / 母巢）不变，统一「暗色主体 + 高饱和主题色发光边缘 + 强对比机理细节」，观感达到本仓库传说宠物（幽域龙裔 / 星噬之眼）的分层立绘精度。
- 全部 Boss 用程序化 Graphics 绘制进 **64×64** 图集 cell，画面中心 (32,32)；主体最大可辨识半径 ≤26-27（为描边/辉光留边，不溢出 cell）。
- 静态单帧：动态交由渲染层（受击闪白、减速染色、施法警示环、Boss 呼吸），**不新增动画帧/外部素材**。
- 后续新增 Boss（关卡/无尽/远征等）必须按「10.2 七层流程」+「10.3 配色表风格」落地，绘制后按 10.5 验收。

### 10.2 七层绘制流程（每只 case 内依次执行）

1. **主题光座/背景符环**：每只一个专属细双环或衬底（半径 27-30、低 alpha），作身份标识；
2. **主题色外发光** `glow(g, 32, 32, r≈28-30, 主题色, 0.4-0.6)`；
3. **暗色主体**：`C.deep` 或专属暗色（alpha ≥0.95），必要时叠 1-2 个次级球/块制造剪影体积；
4. **粗深描边**：宽 2.4-3.2、近黑深色，比旧版更粗更清晰；
5. **体积高光**：左上亮斑 + 下部微反光 + 边缘暗角；
6. **主题机理细节**：瞳孔 / 裂纹 / 表针刻度 / 旋臂冰晶 / 口器利齿 / 蜂窝巢室卵囊等逐只补层次；
7. **边缘加亮 rim/点缀**：细亮环、星子、光点，保证暗底上依旧醒目。

### 10.4 动感与渲染规范（Renderer.ts）

- Boss 本体呼吸：`BOSS_BREATHE=0.028`（≈2.8% 缩放）、频率 2.4Hz、相位按敌人下标错开（同屏多 Boss 不同步）；只改渲染宽高，**不改碰撞/技能半径**。
- Boss 颜色分支：非受击/非减速时 `tint=0xffffff、alpha=1`（本体最亮）。
- 受击闪白 / 减速蓝染 / 施法警示环（`Renderer.ts` warnSprites）为既有表现，均保留；Boss 不新增动画帧。

### 10.5 验收清单（新增/重绘 Boss 必须全部通过）

- 六只 Boss 视觉风格一致（暗底 + 主题发光 rim + 机理层次），精细度与传说宠物同档；
- 在深渊暗色地板上仍能一眼辨识主体轮廓与眼睛/核心；
- 64×64 cell 内无溢出/裁切，主体半径 ≤27；
- 不依赖外部素材；数据/AI/碰撞零改动，typecheck 通过；
- 无尽多 Boss / 特殊三连批同屏时呼吸观感自然（错相）。
