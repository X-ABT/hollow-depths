## 二、武器（基础 7 把 + 进化 7 个）

最多同时装备 **6 把**武器。武器满级 **Lv8**；数值数组按 **Lv1 → Lv8** 排列。
进化形态替换原槽位，不额外占槽（进化后 `maxLevel=1`）。

### 1. 裂地印记（起始武器）

> 在敌人脚下撕裂大地，短暂延迟后爆发。

- **CD(s)**：2.4 / 2.2 / 2.0 / 1.85 / 1.7 / 1.55 / 1.4 / 1.25
- **伤害**：12 / 16 / 20 / 26 / 32 / 40 / 50 / 62
- **爆发半径**：56 / 60 / 65 / 70 / 76 / 84 / 92 / 104
- **印记数量**：1 / 1 / 2 / 2 / 3 / 3 / 4 / 5

机制：对**离玩家最近的** N 个敌人脚下放延迟标记，**0.6s** 后爆发；场上无敌人时落在附近随机点。
进化：+ **锐锋石** → **深渊裂隙**

### 2. 圣环（常驻型）

> 光球环绕自身旋转，持续灼烧并轻微击退靠近的敌人。

- **CD**：常驻（不走冷却，仅用于生成/重建光球）
- **伤害**：8 / 10 / 13 / 16 / 20 / 25 / 30 / 38
- **光球数量**：1 / 2 / 2 / 3 / 3 / 4 / 4 / 6
- **环绕半径**：70 / 74 / 78 / 84 / 90 / 96 / 104 / 116

机制：轨道速度 2.3 rad/s，光球半径 `15 + 等级×0.8`，击退 60，穿透无限。
进化：+ **双面镜** → **双生圣环**

### 3. 追猎印记

> 自动锁定最近敌人的追踪符文。

- **CD(s)**：1.6 / 1.5 / 1.4 / 1.3 / 1.2 / 1.1 / 1.0 / 0.9
- **伤害**：10 / 13 / 16 / 20 / 25 / 30 / 38 / 48
- **符文数量**：1 / 1 / 2 / 2 / 3 / 3 / 4 / 5
- **飞行速度**：300 / 315 / 330 / 345 / 360 / 375 / 395 / 415

机制：追踪转向率 7.5，击退 40，存活 3.2s。
进化：+ **狂怒石** → **猎杀连锁**

### 4. 震击波

> 以自身为中心爆发冲击，强力击退被围困时的敌人。

- **CD(s)**：3.2 / 3.0 / 2.8 / 2.6 / 2.4 / 2.2 / 2.0 / 1.8

### 5. 碎星弹

> 向四周散射星屑碎片，成型后清潮极快。

- **CD(s)**：0.55 / 0.5 / 0.46 / 0.42 / 0.38 / 0.34 / 0.3 / 0.26

### 6. 贯穿光束

> 朝最近敌人射出贯穿一切的光柱。

- **CD(s)**：2.6 / 2.4 / 2.2 / 2.0 / 1.85 / 1.7 / 1.55 / 1.4

## 四、进化（7 组）

**触发**：基础武器 **满级(Lv8)** + 持有指定被动（被动等级不限），升级三选一时出现。
进化数值以基础武器**满级(Lv8)那一行为锚 × 系数**（不是从 Lv1 起算，避免「进化反而变弱」）；
凡是机制自带乘法收益的形态（必暴/溅射/双向…），单发伤害系数会适当下调做补偿。
进化单层固定（maxLevel=1），不额外占槽。

> 平衡目标：进化后的**综合输出 ≈ 满级基础的 1.1~1.25×**，质变主要来自专属机制。

| --- | --- | --- | --- | --- |
| 裂地印记 | 锐锋石 | **深渊裂隙** | 伤害 ×0.72、半径 ×1.15、印记数 ×1.0、CD ×0.9 | **必定暴击**（≈×1.5~2.75，总伤反超满级） |
| 圣环 | 双面镜 | **双生圣环** | 伤害 ×1.15、光球数 ×1.0、环绕半径 ×1.1 | 内外**两圈反向旋转**（数量不变只重排） |
| 追猎印记 | 狂怒石 | **猎杀连锁** | 伤害 ×0.9、符文数 ×1.0、速度 ×1.15、CD ×0.85 | 每发命中**溅射**（半径 82），单体略降补群伤 |
| 震击波 | 疾风符 | **瞬息震荡** | 伤害 ×0.85、半径 ×1.1、击退 ×1.1、CD ×0.7 | 高频解围波（CD 1.8s → **1.26s**） |

### 进化效果详解（逐一）

**① 深渊裂隙**（裂地印记 → 锐锋石）
- 触发：裂地印记 **Lv8** + 持有锐锋石（任意等级）。
- 数值（满级基准）：伤害 62 → **44.6**（因必暴下调）、爆发半径 104 → **120**、印记数保持 **5**、CD 1.25 → **1.13s**。
- 专属机制：每处印记**必定暴击**（暴击率 100%，乘锐锋石提供的暴伤 ≈×1.5~2.75）。面板单发略低于满级，但发发暴击，实际总伤害稳定反超满级（锐锋石等级越高越强），是群怪大范围终结手段。

**② 双生圣环**（圣环 → 双面镜）
- 触发：圣环 **Lv8** + 持有双面镜。
- 数值（满级基准）：伤害 38 → **43.7**、光球总数保持 **6**（+被动加球）、环绕半径 116 → **128**。
- 专属机制：光球按总数拆成**内外两圈反向旋转**（外圈顺、内圈逆），同样 6 球覆盖角度翻倍、无明显死角，全身持续灼烧不降伤反升。

**③ 猎杀连锁**（追猎印记 → 狂怒石）
- 触发：追猎印记 **Lv8** + 持有狂怒石。
- 数值（满级基准）：伤害 48 → **43.2**、符文数保持 **5**（+被动加发）、速度 415 → **477**、CD 0.9 → **0.77s**。
- 专属机制：每发符文**命中即溅射**（半径 82，伤害同符文），单体略降、群伤显著增强，追踪符文变体为「打一个炸一片」。

**④ 瞬息震荡**（震击波 → 疾风符）
- 触发：震击波 **Lv8** + 持有疾风符。
- 数值（满级基准）：伤害 72 → **61.2**、半径 210 → **231**、击退 420 → **462**、CD 1.8 → **1.26s**。
- 专属机制：冷却大幅缩短但仍保留高数值大范围，配合疾风符攻速可做到被围时持续全向爆发，几乎是高频「清场按钮」。

**⑤ 星陨暴雨**（碎星弹 → 疾风符）
- 触发：碎星弹 **Lv8** + 持有疾风符。
- 数值（满级基准）：伤害 27 → **20.25**、弹幕 8 → **12**（+被动再加）、CD 0.26 → **0.23s**、速度保持 560。
- 专属机制：以数量换总伤，每秒投放量更多、更密，清潮总量 ≈ 满级 1.25×，屏幕弹幕雨观感拉满。

**⑥ 苍穹裂光**（贯穿光束 → 双面镜）
- 触发：贯穿光束 **Lv8** + 持有双面镜。
- 数值（满级基准）：伤害 70 → **59.5**、光柱长 540 → **648**、最大穿透 14 → **17**（+被动）、CD 1.4 → **1.19s**。
- 专属机制：同一时刻向**前后双向**射出光柱（朝最近敌人 + 完全反向），单束略降但覆盖面×2，可同时贯穿两路敌潮。

**⑦ 寒霜随行**（霜噬领域 → 智慧卷轴）
- 触发：霜噬领域 **Lv8** + 持有智慧卷轴。
- 数值（满级基准）：DPS 31 → **37.2/s**、半径 168 → **193**、持续 4.5 → **5.0s**、CD 2.5 → **2.13s**。
- 专属机制：领域**跟随自身移动**（持续伤害仍不暴击，避免数值爆炸），配合减速 0.6 边走边铺霜带，把移动路径变成持续死亡地带，覆盖时间利用率远超原地施放。

## 八、Boss（3 个）与技能详解

共同规则：

- 顶部居中显示 Boss 血条，含 `当前HP/最大HP` 数字（即时吸附，无过渡延迟）；
- 场上存在 Boss 时普通怪生成速率 **×0.12**（聚焦 Boss 与其召唤物）；
- 护甲为**固定减伤**（每次受击扣减）。

| Boss | HP | 速度 | 伤害 | 半径 | 护甲 | 经验 | 出现时机 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **古神** | 1500 | 66 | 24 | 46 | 3 | 220 | 开局 **5:00** |
| **灾厄** | 3000 | 58 | 28 | 52 | 6 | 380 | 击败古神后 **4:00** |
| **终焉** | 6000 | 46 | 32 | 58 | 10 | 700 | 击败灾厄后 **4:00** |

> 出场为**事件驱动**：古神固定 5:00；之后每击败一个 Boss 隔 **240s（4 分钟）** 出下一个。HUD 左上角实时倒计时。

### 古神（三阶段，按血量切换）

`>66%` 阶段 0；`>33%` 阶段 1；否则阶段 2。技能统一带 **0.7s 蓄力警示**，安全间歇 **2~3s** 随机。

- **阶段 0（>66%）—— 周期召唤**
  全速追击；周期召唤 **3 只亡魂骚扰怪**（血量倍率 **3.2**，经验极低 0.3）。

- **阶段 1（66%~33%）—— 霜噬领域（落点伤害区）**
  移速 0.7 倍；锁定玩家当前位置为落点，先 **1.4s 落点警示**（长于通用前摇，留足走位时间），随后留下寒霜领域：**半径 105、每秒伤害 10、持续 2.2s**。
  > 定位为"逼迫走位"：原为每秒 14 伤害、持续 4s（总约 56），已大幅削弱。

- **阶段 2（<33%）—— 冲撞**
  移速 0.8 倍；循环 0.7s 警示 → 冲刺 1s（速度 ×3.2）；冲刺结束后**不再召唤**伴生怪。

### 灾厄（全屏预警 AOE）

- 全速追击；每 **3.4s** 发动一次：0.7s 蓄力警示（锁定玩家位置为锚点）→ 释放 **3 个预警圈**（半径 118，预警 **1.2s** 后爆发，伤害 28）；
- 第 1 个落在锚点，另 2 个随机偏移 **±200px**。

### 终焉（边界收缩 + 弹幕，含无敌阶段）

出场进入**无敌倒计时阶段**（30s）：

1. **无敌阶段（30s，不受伤害，只能躲）**
   - 屏幕边界**固定 900**，**不再收缩**（原会从 900 收缩至 260，已改为保持 900）；
   - 环向弹幕：每轮 0.7s 警示 → **14 发**环形直线弹（速度 210、伤害 22、存活 5s）。
2. **破防（30s 后）**
   - 解除无敌与收缩，转为**近身锥形弹**：每轮 0.7s 警示 → **6 发**锥形弹（速度 260、伤害 20、存活 4s）；
   - **破防后才可被击杀**，击败终焉即通关。

## 十一、灵魂经济与跨局商店（Meta）

**货币**
- 单位「灵魂」，**跨局永久**保存于 `localStorage`（`Storage.ts`），显示两位小数（100 击杀 = 1.00 灵魂）。
- 局内击杀即时计入 `world.soulCents`（内部整数，单位 = 0.01 灵魂，避免浮点误差）：普通怪 +1、精英 +10、Boss +1000（即普通 +0.01 / 精英 +0.1 / Boss +10）。
- 一局结束（胜/负/超时兜底都会结算）自动转入永久账户；结算页与复制文案显示「本局凝聚灵魂 +X.XX」。

**商店（仅主界面可打开）**
- 主界面「商店」按钮 + 灵魂余额；对局中无法打开。
- 商品 = 所有未解锁的**武器 / 被动**（固定全列表明码标价），已解锁项标「已解锁」。
- 所有商品共用**累进价**：当前价格 = `3 + 历史已购次数`（首件 3 灵魂，每买一件 +1，跨局累计、无硬上限）。
- 购买即永久解锁，之后该武器/被动才进入每局升级三选一的随机池；已持有的内容每局照常可升级，不受商店限制。
- 进化前置被动同样需要解锁才会出现在升级池（例如把某武器升满后想进化，必须先解锁对应的被动）。

**永久起始等级（升级技能）**
- 已解锁的武器/被动可在商店花灵魂**永久提升「起始等级」**：升级后，本局刷到该内容即从升级后的等级起算（而非 Lv1）。
- 价格逐次翻倍：`30 × 2^(当前起始等级 − 1)` → 升到 Lv2 花 30、Lv3 花 60、Lv4 花 120、Lv5 花 240…（武器封顶 Lv8、被动封顶 Lv5）。
- 数据持久化于 `Storage.ts` 的 `weaponLevels` / `passiveLevels`；初始武器「裂地印记」缺省起始 Lv1，可从商店起手拉高。

**新玩家默认已解锁**（定义于 `Storage.ts` 的 `DEFAULT_UNLOCKED_*`）
- 武器：裂地印记（角色自带）、贯穿光束。
- 被动：智慧卷轴。
- 其余 5 把武器 + 7 件被动均需商店购买解锁。

## 十二、生成 / 波次 / 节奏规则

**基础常量**（`waves.ts`）

- 宽限上限：`RUN_SECONDS = 1800`（30 分钟）
- 同屏软上限：`MAX_ALIVE = 1500`
- 开局缓冲：`GRACE_SECONDS = 4`（前 4 秒不刷怪）
- 生成环额外边距：`SPAWN_MARGIN = 90`（视口外一圈）

**普通怪出场时间轴与权重**

| 时间 | 怪 | 权重 |
| --- | --- | --- |
| 0:00 | 蚁群 | 34 |
| 0:00 | 亡魂 | 26 |
| 1:00 | 史莱姆 | 16 |
| 2:00 | 幻影 | 6 |
| 3:00 | 漩涡虫 | 16 |

**精英出场与刷新**

| 时间 | 精英 | 权重 |
| --- | --- | --- |
| 4:00 | 分裂魔 | 40 |
| 5:00 | 甲壳兽 | 30 |
| 6:00 | 欺诈者 | 30 |

首个精英 4:00 出现，之后每 **26s** 刷一只。

**密度与速率**

- 每秒生成数 `spawnRate(t) = min(34, 0.6 + t × 0.052)`（随分钟线性增长，上限 34/s）
- 密度倍率阶梯：0:00 ×1 → 2:00 ×1.5 → 6:00 ×2 → 9:00 ×2.5 → 11:00 ×3
- **击败古神前**普通怪生成率 **×0.5**（开局更从容）；**击败古神后**升到 **×0.7**
- Boss 存活时普通怪生成率再 **×0.12**

**方向轮换刷新**（缓解四面围堵）

普通怪不再四面八方同时涌来，而是按 **上 → 右 → 下 → 左 顺时针**，**每 5 秒**换一个主方向，在方向扇区（±0.9 rad ≈ ±51°）内散布生成，留出可走位的方向。

**分离力与怪群缝隙**

- 分离力强度 240；怪与怪保持**最小缝隙 12px**（距离小于"半径和 + 12"即柔和推开），使潮水间始终留有可穿插的缝。
- Boss 只受 **12%** 的分离力（Boss 推小怪，而非被小怪推走）。

## 十三、胜负规则

- **胜利**：击败最终 Boss「**终焉**」即获胜（终焉破防后才可被击杀）。
- **失败**：角色生命归零。
- **兜底**：若 **30 分钟**内仍未击败终焉，也判负（防无限拖局）。
- Boss 出场：古神 5:00 → 击败后 4 分钟出灾厄 → 击败后 4 分钟出终焉；HUD 左上角显示下一个 Boss 的实时倒计时。

## 十四、宠物系统（饲养园 + 宠物园）

宠物通过「灵魂抽奖」获得宠物或粮食，在饲养园投喂升级，是**跨局养成**内容；每局最多 3 只上阵（上阵槽按拥有数解锁：默认 1、拥有 5 只 → 2、10 只 → 3）。

另有独立「**宠物园**」（主界面按钮进入）：一块绿地展示场景，把所有已拥有宠物按**当前养成体型**放上展台做待机动画，支持拖拽平移 / 缩放 /「适应全部」；点击宠物查看稀有度、Lv、体积/血量/伤害与体型比例，并可**原地投喂升级**（喂完体型即时变大）。展示与局内战斗上阵**相互独立**。

### 抽奖（`pets.ts` GACHA_*）

- 单抽 **200 灵魂** / 十连 **1800（9 折）** / **百连 16000（8 折，一次 100 抽）**；
- 每抽 **90%** 出宠物粮、**10%** 出宠物；粮袋单次数量 1/5/10/20/50/100 按权重（常见 1 袋，罕见 100 袋）；
- 10% 宠物内部概率分层：普通 **9.5%** / 稀有 **0.49%** / 传说 **0.01%**（同层内均分）；
- 重复宠物自动分解碎片：普通 20 / 稀有 60 / 传说 200；
- 碎片商店：指定宠物兑换价 普通 150 / 稀有 400 / 传说 1200；粮袋 **2 碎片/袋**，另有整包特惠 **100 碎片 = 100 袋**。

### 宠物与成长（抽奖池 12 只 + 基础赠送 1 只）

| 稀有度 | 数量 | 基础 体积/血/伤 | 每级体积成长 |
| --- | --- | --- | --- |
| 普通 | 6（噬魂蝠、锈壳虫、骨堆犬、纸灯灵、雾蛙、腐芽精） | 6 / 20 / 3 | +1 |
| 稀有 | 4（深渊猎犬、晶甲龟、噬光蝶、霜魇猫） | 8 / 35 / 5 | +1.5 |
| 传说 | 2（幽域龙裔、星噬之眼） | 10 / 60 / 8 | +2 |
| 基础赠送 | 1（翠芽团子，绿圆球，**不进抽奖/兑换池**，仅领取一次） | 3 / 10 / 1.5 | +1 |

- 升级：**血量 +1、伤害 +1**（每级，所有宠物一致）；体积按上表幅度成长（普通与传说拉开差距）；
- 升级粮耗：Lv.n → n+1 需 `5 + (n-1)×2` 袋粮（5 / 7 / 9 / 11…）；
- **无等级上限**；局内视觉大小 = 基准宽 × 当前体积 ÷ 基础体积（线性连续，每一级都在变大）。

### 局内出战（`PetSystem.ts`）

- 跟随玩家，自动扑向最近敌人；攻击为**单体爪击**（一次只打一个目标，只对该目标结算一次伤害），命中处闪现「三条竖线」爪痕；索敌半径 ≈ `34 × 体积比例`，封顶约 460；攻击随体型略放缓；
- 被敌人近身掉血，归零**不死亡**：灰心逃回玩家身边（期间无敌），数秒后满血回归；
- 体积过大时可从暂停弹窗开「宠物紧凑显示」，隐藏巨兽本体避免遮屏（攻击特效仍在）。
- 数据出处：`data/pets.ts`、`ui/PetScreen.ts`、`ecs/World.ts`（宠物池）、`render/TexKeys.ts`（Pet+ 贴图）。
